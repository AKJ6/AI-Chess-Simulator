Build a local AI-vs-AI chess application in Python where two LLM-based agents play chess against each other automatically. The application must use PySide6 for the GUI and JSON for persistent board state storage.

========================================
PROJECT GOAL
========================================

Create a chess simulator where:
- Two AI chatbots/models play against each other
- Each model controls one color only
- The game board is stored in JSON
- Chess rules are enforced programmatically
- The GUI updates live using PySide6
- Turns alternate automatically
- All moves are logged
- Stalemates are resolved using remaining piece values

========================================
TECH STACK
========================================

Language:
- Python 3

GUI:
- PySide6

Models:
- Quantized local models
- Example:
  - Qwen
  - Gemma

Storage:
- JSON files

========================================
APPLICATION FLOW
========================================

1. main.py starts the application
2. Load GUI
3. Load both AI models into memory
4. Initialize chess board JSON
5. Controller starts game loop
6. Current AI receives board state
7. AI suggests a move
8. Move validator checks legality
9. If valid:
   - update JSON
   - update GUI
   - log move
   - switch turn
10. Repeat until:
   - checkmate
   - stalemate
   - illegal move limit
   - max move limit

========================================
BOARD REPRESENTATION
========================================

Store board as an 8x8 JSON matrix.

Each square contains either:
- null
OR
- a piece object

Example piece object:

{
    "type": "pawn",
    "value": 1,
    "color": "white",
    "has_moved": false
}

========================================
PIECE VALUES
========================================

Pawn = 1
Knight = 4
Bishop = 4.5
Rook = 5
Queen = 9
King = 11

========================================
STARTING BOARD FORMAT
========================================

Example:

[
  [
    {"type":"rook","value":5,"color":"black"},
    {"type":"knight","value":4,"color":"black"},
    ...
  ],
  ...
]

========================================
MOVE VALIDATION RULES
========================================

Implement complete chess validation:
- Pawn movement
- Pawn capture
- Double pawn first move
- En passant
- Promotion
- Knight L movement
- Bishop diagonals
- Rook straight lines
- Queen combined movement
- King one-step movement
- Castling
- Check detection
- Checkmate detection
- Stalemate detection

Moves must fail if:
- Piece belongs to wrong player
- Destination invalid
- Path blocked
- King remains in check

========================================
MODEL RESPONSIBILITY
========================================

White AI:
- Can only move white pieces

Black AI:
- Can only move black pieces

Both models:
- Receive entire board state
- Return move suggestion in structured format

========================================
MOVE FORMAT
========================================

Use standardized move JSON:

{
    "from": [6,4],
    "to": [4,4]
}

========================================
CONTROLLER RESPONSIBILITIES

========================================
STALEMATE LOGIC
========================================

If stalemate occurs:
- Sum remaining piece values
- Team with higher score wins

Example:
White remaining = 22
Black remaining = 17

Winner = White
